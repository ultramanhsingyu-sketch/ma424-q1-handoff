03 · Quick look

The model in one picture

The state is the number of bikes docked. In each slot a rental moves the chain down by one (probability p), a return moves it up by one (probability q), or nothing happens. At the two ends the failed event leaves the chain where it is.

13 states, 0 to 12. Amber: a return (up). Blue: a rental (down). Red: the ends, where a failure keeps the chain in place.

04 · Starter code

Copy this to the top of your file

It gives you the set-up, the two functions mat_pow() and slot_matrix(), and p, q, P.

starter.R
K <- 12                  # number of docks
h <- 0.5                 # slot length in minutes
slots_per_hour <- 60 / h # 120

# n-step transition matrix (from the lecture)
mat_pow = function(P, n) {
  Pn = diag(nrow(P))
  for (k in seq_len(n)) {
    Pn = Pn %*% P
  }
  dimnames(Pn) = dimnames(P)
  return(Pn)
}

# One-slot transition matrix on the states 0, 1, ..., K
slot_matrix <- function(K, p, q) {
  stopifnot(p + q <= 1)
  M <- matrix(0, K + 1, K + 1)
  dimnames(M) <- list(0:K, 0:K)
  n <- nrow(M)
  M[cbind(2:n, 1:(n - 1))] <- p   # a rental: n -> n-1
  M[cbind(1:(n - 1), 2:n)] <- q   # a return: n -> n+1
  diag(M) <- 1 - p - q            # nothing happens
  M[1, 1] <- 1 - q                # state 0: a failed rental stays at 0
  M[n, n] <- 1 - p                # state K: a failed return stays at K
  M
}

(a) · slot probabilities
p=0.150q=0.125 exponential property Cignored by the model B

An hour has 120 slots and a slot has at most one rental request, so the expected requests per hour are 120p=18 and 120q=15. C: for rate α, a short interval δ contains a request with probability 1−e−αδ=αδ+o(δ). B: the model allows only one event per slot.

Every state reaches every other (0→12 has probability at least q12, 12→0 at least p12), so there is one class {0,1,…,12}. It is closed and finite, so it is recurrent. State 0 can return in one step (p0,0​>0), so the period is 1.
